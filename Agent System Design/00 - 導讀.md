# 導讀

## 這本書為誰而寫

你會寫 Python，可能是後端、全端、資料或 SRE 工程師；你用過 ChatGPT，也呼叫過 LLM API，甚至做過一兩個 demo。可是當主管說「把客服交給 agent」「讓工程師把 issue 指派給 agent」「做一個能跨資料源分析的 research agent」時，你會發現 demo 和可上線的系統之間隔著一大片沒人講清楚的地帶：loop 什麼時候該停、tool 要怎麼設計、context 塞滿了怎麼辦、退款這種動作誰來核准、被 prompt injection 了怎麼擋、改了 prompt 之後怎麼知道沒有變差、成本與延遲怎麼估、出事了怎麼查。

這本書就是為這樣的讀者寫的。目標是讓你**只靠這本書**，就能從零打造一個可上線的 agent，或設計自己的 agentic framework，並且能像做 system design 一樣，完整說明一個 agent system 的架構、取捨、風險、評估與營運。

## 這本書怎麼教

**從一個 100 行的 loop 開始，一路長成完整的 framework。** 第 4 章先寫出最小的 agent loop，之後每一章替它加上一個模組：tool 設計、structured output、context 與 compaction、retrieval、memory、tool search、MCP、sandbox、workflow 與 graph、multi-agent、人工核准、durable execution……到第 23–25 章重構成有清楚抽象的 `loom` v0.5，第 45 章組裝成 v1.0，並附上可以直接執行與測試的隨書程式碼。

**每段程式都能離線執行。** 全書只用 Python 標準函式庫，並用一個依劇本回應的假模型 `ScriptedModel` 驅動所有範例，所以你不需要 API key，也不會因為模型的隨機性看到不一樣的結果。書中貼出的執行輸出都是實際跑出來的。接真實 API 的寫法另外以範例列出，並標明「依 2026 年 10 月的 SDK 介面」。

**用一家公司的故事串起全書。** 青鳥科技做電商營運 SaaS，團隊從一個會查訂單、會退款的客服 agent 開始，接著做內部 coding agent 與營運 research agent，最後把共用的部分抽成自家 framework。每章都從青鳥真實可能遇到的事故開場：無限迴圈燒掉一週預算、逾時重試退了兩次款、摘要把使用者的交代弄丟、顧客在訂單備註裡夾帶指令。你會看到每一個設計決定是為了解決什麼問題。

**原理為主，現況為輔。** agent 領域變化很快，所以正文講的是不容易過時的原理與取捨；版本號、價格、benchmark 分數、產品細節一律放在標明「2026 現況」的區塊，並寫明查證日期。這本書在動筆前做了完整的技術 survey，涵蓋框架與協定、核心技術與市面成功產品的架構、評估、可觀測性、安全與治理。

## 每一章長什麼樣子

| 區塊 | 內容 | 讀的時候注意什麼 |
|---|---|---|
| 本章地圖 | 核心問題、讀完能做到什麼、前置知識 | 先確認前置章節讀過了 |
| 故事 | 青鳥遇到的具體問題 | 記住事故，後面每一節都在回答它 |
| 核心概念 | 為什麼需要、怎麼運作、主流產品怎麼做、取捨與誤解 | 每張圖都跟著文字走一遍 |
| 動手做 | 可離線執行的 Python 與實際輸出 | 自己執行一次，改參數看結果怎麼變 |
| 實務應用 | 三個以上的產業情境與主流做法 | 想想自己的系統對應哪一個 |
| 設計檢查清單 | 設計或審查時逐項回答的問題 | 直接拿去做 design review |
| 常見錯誤與除錯 | 症狀、原因、怎麼確認、怎麼修 | 上線後出事時回來查 |
| 重點整理與延伸問答 | 8–15 條重點、8 題附答案的問答 | 先自己回答再展開答案，確認真的吸收了 |

## 怎麼讀

- **第一次接觸 agent**：照順序讀 Part 0 到 Part 2，每章的動手做都自己跑一次。讀完你就能寫出一個不會失控、可測試的 agent。
- **要把 agent 帶上 production**：Part 1 之後，優先讀第 21–22 章（核准與 durable execution）、Part 6（評估與可觀測性）與 Part 7（安全），再讀 Part 8。
- **要自己做 framework**：讀完 Part 1–4 後直接進 Part 5，再到第 45 章對照隨書程式碼。
- **準備 agent system design 面試**：先讀第 35 章的方法論，再做第 42–44 章三場演練，最後用附錄 E 的 30 題自我檢驗。
- **只想查某個主題**：附錄 C 是框架與協定速查，附錄 D 是可直接使用的 checklists，附錄 A 是術語表。

## 本書不涵蓋什麼

本書不教模型訓練與 transformer 的內部原理（只在第 3 章講 agent 建造者需要的部分），也不逐一教每個框架的 API；第 26 章與附錄 C 會告訴你各框架的設計哲學與選型方法，細節請以官方文件為準。安全章節只談成因、偵測與防禦設計，不提供攻擊手法。

準備好了，就從第 1 章開始。
