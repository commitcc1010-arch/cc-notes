# 導讀

## 這本書為誰而寫

你會寫 Python，學過陣列、hash table、linked list、tree、graph 這些基本資料結構，也許已經在 LeetCode 上寫過幾十題甚至幾百題。可是真正坐在面試官面前時，常常會遇到三種狀況：題目看起來眼熟，卻想不起關鍵觀察；想到做法了，寫到一半才發現邊界處理不了；好不容易寫完，面試官一句「如果資料是串流呢？」就接不下去。

這本書就是為這樣的讀者寫的。目標是讓你**只靠這本書**，在 2–3 週內準備到 Google L5（senior）同等級的 coding interview：能在時間內寫出最佳或接近最佳的解、程式乾淨、主動測試與處理邊界、清楚說明複雜度與取捨，並能應付連續的 follow-up。只要能在這個標準下穩定表現，其他大廠同等級的 coding 回合通常也能應付。

## 為什麼用 pattern 來準備

LeetCode 上有幾千題，不可能全部寫過，也不需要。大廠 coding interview 的題目雖然千變萬化，背後反覆出現的解題結構其實只有二、三十種：看到「排序陣列裡找邊界」就想到 binary search，看到「連續子陣列的最長／最短」就想到 sliding window，看到「依賴關係」就想到 topological sort。本書把這些結構整理成 26 個 pattern，每個 pattern 一章。

背題和學 pattern 的差別，在面試遇到沒看過的題目時最明顯。背題的人只能比對「這題有沒有寫過」；學 pattern 的人會問「這題的限制條件允許什麼複雜度？題目有哪些訊號？哪個 pattern 的 invariant（不變量）能套上去？」本書每一章都在訓練後面這種思考方式。

## 一個 pattern 章長什麼樣子

第 4 章到第 29 章，每章的結構都一樣，熟悉之後可以很快找到需要的部分：

| 區塊 | 內容 | 讀的時候注意什麼 |
|---|---|---|
| 本章地圖 | 一句話本質、辨識訊號、本章題目 | 先記住辨識訊號，這是面試時最先用到的東西 |
| 開頭小節 | 這個 pattern 解決什麼問題、辨識訊號表、模板與原理、常見錯誤 | 模板要能默寫，並說得出每一行為什麼這樣寫 |
| 5 道核心題 | 這個 pattern 一定要會的標準形 | 每題都要自己寫出來，寫不出來就是還沒學會 |
| 5 道難題 | 這個 domain 的上限與主要變形 | 先看提示自己想，再讀詳解；至少要能講出關鍵突破點 |
| Pattern 歸納 | 所有變形、上下限、和其他 pattern 的關係 | 複習時最先讀這一節 |
| 本章重點整理 | 條列重點 | 考前一天快速掃過 |

每道題都包含完整的題目重述（不必打開 LeetCode）、從暴力解講起的思路、至少一個文字視覺化、可直接執行並附測試的 Python 解法、複雜度與邊界分析，以及至少三個面試官真的會追問的 follow-up 與具體答案。難題另外附三段由淺到深的摺疊提示和一段心得。

## 怎麼讀才有效

讀解答很容易產生「我懂了」的錯覺，真正的檢驗是闔上書自己寫。建議每題都照這個流程：

1. 讀完題目就開始計時自己解（核心題 15–20 分鐘、難題 30–40 分鐘，都包含寫程式的時間），第一步先說出暴力解和它的複雜度。
2. 卡住時，難題就打開提示，一次只看一段；核心題沒有提示，改讀「思路」的第一段再自己寫。
3. 自己寫程式，用題目範例和邊界案例手動追蹤，再執行書中的測試。
4. 讀思路或詳解，對照自己的做法差在哪裡。
5. 回答 follow-up 前先自己想一分鐘，再展開答案。
6. 寫不出來或寫錯的題，記到錯題本，依第 1 章的間隔重複規則複習。

詳細的 21 天、14 天與 7 天計畫在附錄 D；第 1 章說明背後的理由與每天的練習流程。

## 本書的寫作原則

- **自給自足**：每題完整重述，每個術語第一次出現就解釋，Python 用法不熟可以查附錄 A。
- **只用 Python**：Python 3.11+ 與標準函式庫。所有程式都經過自動執行驗證，每段都附測試。
- **不照抄**：題目一律用自己的話重述，範例多半重新設計；題號標的是 LeetCode 題號，方便你另外上線練習。
- **不捏造**：各公司的面試傾向只寫公開資訊與普遍經驗，不寫出現頻率或統計數字。面試流程會變動，以 recruiter 告知的為準。
- **以 L5 標準撰寫**：思路要講清楚「為什麼想到」，follow-up 要具體到做法與複雜度，心得要說明面試時怎麼講。

## 本書不涵蓋什麼

Google L5 等級的完整面試流程通常還包含 system design 與 behavioral 回合，這兩者不在本書範圍內。本書也不教程式語言入門：讀者需要能用 Python 寫函式、迴圈與基本的 class。若你對 Python 的內建資料結構還不熟，先花一個晚上讀附錄 A，再開始第 1 章。

準備好了，就從第 1 章開始。
