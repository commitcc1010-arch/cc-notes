# Big Tech Last-Mile Playbook

[[00 - Book Index|回到目錄]]

## Google

最後一週重點：

- Graph、DP、binary search on answer、數學轉換。
- 練習從陌生敘述抽象出狀態與 invariant。
- 每題都口述 correctness 與複雜度。
- 不依賴背過的函式名稱；練習自行定義 helper。

## Meta

訓練節奏：

- 17 分鐘第一題。
- 17 分鐘第二題。
- 1 分鐘最後檢查。

優先熟練：

- Hashing、two pointers、sliding window。
- Tree traversal、interval、stack。
- 短而正確的 implementation。

## Amazon

除了演算法，主動展示：

- 清楚命名與 helper 邊界。
- 空輸入、重複值、overflow 與極端大小。
- 寫完立即提出測試。
- Follow-up 中討論 maintainability 與 production trade-off。

## Microsoft

優先熟練：

- Hash map 與字串。
- DP。
- Linked list、tree 與 implementation-heavy 題目。
- 清楚處理 null、index 與 mutable state。

## 面試前三天

### T-3

- 兩場完整 mock。
- 找出三個最弱 pattern。

### T-2

- 每個弱 pattern 重做一題核心＋一題上限題。
- 複習語言 API。

### T-1

- 不再大量刷新題。
- 重寫 templates。
- 看紅黃題的錯誤原因。
- 確認面試環境、時間與允許工具。
