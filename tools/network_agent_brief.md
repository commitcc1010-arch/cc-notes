# 撰寫任務說明（給章節撰寫 agent）

你正在撰寫新書《從封包到即時影音：工程師的網路全書》（書稿目錄 `Networking Book/`，repo 根目錄 `/Users/chouwleo/Projects/cc-notes`）。目標：讓 junior engineer **只靠這本書**就能完整認識整個網路，從封包、TCP、DNS、TLS、HTTP，到 JWT、OAuth、WebSocket、WebRTC、SDP、SRT、WSGI／Werkzeug 與雲端網路；深入淺出、循序漸進，深度與廣度兼備，並有大量視覺化與實務例子。

## 開始前必讀（依序）

1. `tools/network_style_guide.md`：寫作規範，全部遵守，尤其第 3 節（章節結構）、第 4 節（程式碼規則：只用標準函式庫、只在 127.0.0.1 與 port 0、不連外網）、第 7 節（準確性）、第 8 節（禁止事項）。
2. `tools/network_outline.md`：全書大綱。找到你負責章節的「必須涵蓋」清單，全部講到，並補上你知道的重要知識點。了解其他章講什麼，交叉引用寫「第 N 章」，不要重複其他章的主題（簡短提及並指向該章即可）。
3. `tools/network_canon.md`：全書共用設定（若已存在），必須一致。
4. 技術現況 survey（若已存在）：`tools/.network_survey.md`。會變動的資訊依它的查證狀態處理。
5. 範本章（若已存在）：`Networking Book/Part 2 - 傳輸層/10 - TCP 連線.md`。學它的敘事、深度、圖表密度、程式與輸出解說、實務與問答品質。

## 重點要求

- 每個新名詞第一次出現就白話解釋並舉例；每個機制講清楚「為什麼需要、怎麼運作、真實系統長什麼樣、取捨與常見誤解」。header 與封包一定畫位元布局圖，流程一定畫時序圖。
- 用聲聲 Live 的具體情境開場並貫穿全章。
- 視覺化：至少 4 張 ```text 圖與 3 張表格，每張圖後逐步解說。
- 動手做：可在 localhost 離線執行的 Python（只用標準函式庫），實際執行後把輸出貼在緊接的 ```text 區塊並逐步解說。章內其他段落也鼓勵放小段可執行程式。
- 正文約 15,000–26,000 可見字元（不含問答與程式碼）。

## 自我檢查（必做）

在 repo 根目錄執行：

```bash
python3 tools/check_network_book.py <你的章號>
```

checker 會單獨執行每段 Python、檢查結構、圖表數量、中英文空格、URL、第三方 import、性別代名詞與非包容性用語。修到 **0 errors** 並處理 WARN，再從頭讀一次自己的章。
