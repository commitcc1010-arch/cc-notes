# 導讀

## 這本書為誰而寫

你會寫 Python，用 Flask 做過 API，也呼叫過別人的 HTTP 服務。你知道「DNS 把名字變成 IP」「HTTPS 比較安全」「WebSocket 可以即時推播」，但這些知識是零碎的：一旦 production 出現「某些使用者連不上」「API 偶爾 502」「視訊單向沒聲音」「改了 DNS 還是連到舊機器」，你不知道該從哪一層查起，也說不清楚為什麼。

這本書就是為這樣的 junior engineer 寫的。目標是讓你**只靠這本書**，就能完整認識整個網路：從網卡送出的第一個 frame，到 IP 路由、TCP 連線、DNS、TLS、HTTP；再到驗證與授權（session、JWT、OAuth、OIDC、passkeys）、即時通訊（SSE、WebSocket）、即時影音（RTP、SDP、WebRTC、SRT、HLS）；最後是 Python 的 Web 伺服器堆疊（WSGI、Werkzeug、ASGI、gunicorn、uvicorn）與雲端網路。讀完之後，你應該能看懂封包與 log、設計正確的 API 與驗證流程、在工作上獨立除錯網路問題，並在系統設計討論中說清楚取捨。

## 這本書怎麼教

**跟著一個真實的系統走。** 全書的貫穿案例是**聲聲 Live**，一個線上語言家教平台：學生在網頁上預約、付款，和老師視訊上課；教室裡有聊天與白板；熱門講座用專業設備直播給上千人。剛入職的 junior 工程師小晴，在資深平台工程師阿德、影音工程師 Joe 與資安工程師 Rita 的帶領下，一章一章遇到真實會發生的事故：連線池造成 CLOSE_WAIT 堆積、憑證過期、CDN 把個人化頁面發給別人、7 天的 JWT 讓停權的老師還能改課表、WebSocket 在部署時引發重連風暴、SDP 裡寫死的 payload type 讓視訊變黑。每個事故都在章節裡被解開，你會知道每個機制「為什麼需要」。

**每個機制都看得見。** 每章都有大量的位元布局圖、時序圖、狀態機與拓撲圖；header 一定畫出每個 bit 的位置，流程一定畫出每一步的往返。

**每段程式都能在你的電腦上跑。** 全書的 Python 只用標準函式庫，全部在 127.0.0.1 上離線執行：你會親手組出 Ethernet、IP、UDP 封包並計算 checksum，寫一個 DNS server 與 resolver，重現 TCP 的各種狀態與 RST，手組 TLS ClientHello，從零實作 HTTP/2 frame、WebSocket、STUN、RTP 與 jitter buffer，跑一次完整的 OAuth＋PKCE 流程，寫一個迷你版 Werkzeug 與 ASGI server。書中貼出的輸出都是實際執行得到的。需要第三方套件（Werkzeug、Flask、uvicorn 等）或真實網路的部分，另外以範例或示意輸出呈現。

**原理為主，現況為輔。** 網路的基本原理很穩定，但標準化進度、瀏覽器支援、憑證效期政策等資訊變化很快。這些會變動的資訊一律放在標明「2026 現況」的區塊，並寫明查證時間（截至 2026 年 10 月）。

## 怎麼讀

- **第一次系統性學網路**：照順序讀 Part 0 到 Part 5，每章的動手做都跑一次。讀完你就有一張完整的網路地圖。
- **後端工程師**：Part 0–5 之後，優先讀 Part 6（驗證與授權）與 Part 9（Python Web 堆疊），再讀第 44、45 章。
- **前端工程師**：第 1、3、14、18、20–23、26–29、31、32 章是核心。
- **SRE 與平台工程師**：Part 1–4 要讀熟，再讀第 25、43、44、45、46 章。
- **影音與即時互動**：第 7、9、12、13 章之後直接進 Part 7 與 Part 8。
- **準備面試**：第 1 章與第 46 章的系統設計與面試題，搭配附錄 E 的學習路線。
- **只想查某個欄位或指令**：附錄 B 是工具指令速查，附錄 C 是協定格式速查，附錄 D 是 port 與 status code 速查。

## 本書不涵蓋什麼

本書不教路由器與交換器的設定（例如特定廠牌的 CLI），也不深入作業系統核心網路堆疊的實作；安全相關章節只談成因、偵測與防禦，不提供攻擊手法。這些主題在需要時會指出延伸閱讀的方向。

準備好了，就從第 1 章那個「首頁要等三秒」的問題開始。
